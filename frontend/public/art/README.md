# Objetos del juego

Cuatro ilustraciones decorativas para el administrador de VÉRTICE. No contienen datos ni representan estadios o trofeos oficiales.

| Archivo | Sección |
| --- | --- |
| `stadium.webp` | Inicio y acceso |
| `catalog.webp` | Catálogo |
| `registration.webp` | Matrículas |
| `matchday.webp` | Partidos |

Generadas con la herramienta integrada de imágenes de ChatGPT (modo built-in, sin CLI). Los originales se convirtieron a WebP, calidad 86, conservando 1536 × 1024 píxeles. La integración, los rótulos y el resto de la interfaz están hechos en HTML/CSS.
