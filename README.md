# VÉRTICE

Mini plataforma web de estadísticas y resultados de fútbol.

## 🎯 Objetivo

Crear una aplicación web que permita consultar partidos de fútbol,
resultados, equipos y estadísticas de forma sencilla y agradable.

La idea es comenzar con un proyecto pequeño y hacerlo crecer
progresivamente mientras aprendemos programación.

## 💭 Idea
VÉRTICE es una plataforma web de información y estadísticas de fútbol
centrada inicialmente en competiciones colombianas y sudamericanas.

El objetivo no es simplemente mostrar resultados, sino crear una
experiencia de navegación en la que el usuario pueda descubrir partidos,
equipos, jugadores y estadísticas de manera natural y agradable.

La interfaz debe priorizar la claridad, la jerarquía visual y la
exploración antes que la cantidad de información mostrada
simultáneamente.

Visión

VÉRTICE debe sentirse como un lugar al que el usuario entra para
consultar un partido y termina explorando otros partidos, equipos,
jugadores e historias relacionadas.

La cantidad de información disponible no debe traducirse en una
interfaz saturada.

La información debe aparecer progresivamente según el contexto y el
interés del usuario.

## 🎯 MVP

El MVP debe permitir:

Consultar partidos de las competiciones seleccionadas.
Consultar partidos pasados, actuales y próximos.
Abrir la página individual de un partido.
Consultar el resultado y estado del partido.
Consultar alineaciones y jugadores.
Consultar goles y eventos.
Consultar tarjetas.
Consultar estadísticas del partido.
Consultar información histórica relacionada.
Explorar otros partidos relacionados.
Explorar equipos y jugadores.
Navegar entre competiciones.

El MVP debe utilizar inicialmente datos reales o una fuente de datos
estructurada y confiable, pero la interfaz y arquitectura deben permitir
cambiar la fuente de datos posteriormente.

matemáticas disponibles públicamente para cada competición.

Organizadores oficiales de las competiciones.
Fuentes oficiales de las federaciones y ligas.

##🧭 Experiencia de navegación

La interfaz debe evitar la saturación visual.

Los principios principales serán:

Jerarquía visual clara.
Información progresiva.
Espacios suficientes entre elementos.
Pocas acciones principales por pantalla.
Estadísticas agrupadas por contexto.
Navegación sencilla.
Uso cuidadoso de color y animaciones.
Diseño orientado a descubrimiento.

El usuario debe poder profundizar en la información sin sentirse
obligado a consumirla toda de una vez.

La interfaz debe priorizar la sensación de exploración y continuidad.

##🚫 Principios que VÉRTICE NO debe seguir
No mostrar toda la información disponible simultáneamente.
No llenar la interfaz de tarjetas innecesarias.
No utilizar banners invasivos.
No sacrificar legibilidad por mostrar más estadísticas.
No crear navegación complicada.
No convertir cada sección en una página visualmente independiente.
No copiar la estructura de sitios deportivos saturados.

La información debe estar disponible sin que la interfaz grite por atención.
